# 分屏关闭显示器

Windows 多显示器分屏关闭工具：可以只关其中 1 台、2 台，或者全部关闭。主机、智能体、下载等后台任务照常运行，ToDesk 等远程软件照常能查看。

典型用法：电脑接一个 HDMI/DP 诱骗器（虚拟屏），开启「远程模式」后断开所有实体屏，只留虚拟屏，电脑看起来是关着的，远程却能正常操作。

## 下载

直接到 [Releases](https://github.com/y1991427360s/monitor-off/releases/latest) 下载单文件 exe：`MonitorOff-*-win-x64.exe` 需要 .NET 8 桌面运行时；`*-standalone.exe` 自带运行时，下载即用。

## 构建与安装

需要 Windows 10/11、[.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)（运行只需 .NET 8 桌面运行时）。

```powershell
git clone https://github.com/y1991427360s/monitor-off.git
cd monitor-off
powershell -ExecutionPolicy Bypass -File .\install.ps1            # 构建到 bin\ 并在项目目录创建快捷方式
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Desktop   # 同时把快捷方式放到桌面
```

## 使用

| 快捷方式 | 作用 |
|---|---|
| `分屏关闭显示器.lnk` | 打开面板：在布局图里点选显示器（可以多选），然后点「关闭 N 台」或「打开 N 台」 |
| `远程模式-关闭实体屏.lnk` | 一键**断开**所有实体屏（本机为 1、2 号）的输出，只留 3 号虚拟屏并让它当主屏；实体屏收不到信号就不会自己亮。程序在托盘里运行 |
| `恢复全部显示器.lnk` | 把所有关掉的显示器打开 |

- **Ctrl+Alt+F12**：随时恢复全部显示器（程序在后台或托盘里时都有效）。
- 点窗口的 × 或 – 只会把程序收到托盘，不会恢复显示器；「保持关闭」和热键继续生效。真正退出请用托盘菜单里的「恢复全部并退出」。
- **保持关闭**（默认开启）：每 20 秒给已关闭的屏补发一次关闭命令。显示器因为 Windows 自动熄屏后又唤醒、信号恢复等原因自己亮起来时，最多 20 秒后又会关掉。
- **碰本机键盘鼠标时自动恢复**（默认关闭）：只响应本机的物理键鼠，`SendInput` 注入的操作会被忽略（已实测）。ToDesk 如果走的是驱动级输入，可能会被当作本机操作，所以远程使用时建议保持关闭。

## 关闭方式（自动选择）

| 情况 | 方式 |
|---|---|
| 默认（勾选「实体屏也用断开输出」）、远程模式、不支持 DDC 的屏 | 断开这一路输出（`SetDisplayConfig` 去掉对应路径）。主屏被断开时，剩下的一台挪到 (0,0) 当主屏 |
| 取消勾选，且显示器支持 DDC/CI | VCP `D6=04` 单独待机，桌面布局不变；但 SKG 实测会自己亮起，只能靠「保持关闭」每 20 秒补关一次 |
| 所有接在桌面上的屏都要断开 | 至少要留一台：支持 DDC 的改用 DDC；都不支持 DDC 就用系统待机 |

恢复顺序：第一次断开之前会保存完整的显示配置快照，全部接回时原样套用这份快照（位置、主屏都还原，已实测）。快照失效时（比如中间重启过，显卡 LUID 会变）改为给每台屏挑一个空闲的源精确接回，最后才兜底用「扩展」拓扑。

## 踩过的坑

- **`\\.\DISPLAYn` 编号会变**：接入或断开输出后，Windows 可能重新分配编号（实测 SKG 从 DISPLAY1 变成了 DISPLAY2）。所以程序用显示器的设备路径（`DisplayConfigGetDeviceInfo` 的 `monitorDevicePath`）识别每一台屏，每次操作前再查出当前的 GDI 名。
- **DDC 待机时读回的 D6 仍是 1**：没法靠读取判断屏是不是关着，所以以程序自己的记录为准；也正因为这样，状态可能和实际不一致，这时选中那台屏重新点一次「关闭」或「打开」就能纠正。
- **断开主屏后剩下的屏会挪到 (0,0)**：直接按当前坐标画布局图，它会和被断开那台记录的位置重叠，编号也会乱。现在没有断开任何屏时，会把布局记成“原始布局”（`settings.json` 里的 `Home`）；断开期间布局图和 1/2/3 编号一律按原始布局显示。
- **SKG H27T22S-3 Pro 用 DDC 待机后会自己亮**：显卡还在送信号，显示器过一阵就会自己醒过来。所以默认改用断开输出。
- **旧版断开（`ChangeDisplaySettingsEx` 宽高写 0）配合「扩展」接回不可靠**：断开时写进系统数据库的配置会被「扩展」原样套用，被断开的屏还是关着（实测 3 号接回失败）。
- **WPF 透明分层窗口（AllowsTransparency）慢**：创建慢而且只能软件渲染，点击发钝。现在改用普通窗口，圆角和阴影交给 Win11 DWM 绘制。

## 文件

- `app\`：C# .NET 8 WPF 源码
  - `MonitorService.cs`：枚举显示器、DDC、断开/接回输出
  - `Store.cs`：设置和关闭记录，保存在 `%APPDATA%\MonitorOff\settings.json`
  - `MainWindow.*`：界面、托盘、热键、键鼠钩子
- `bin\分屏关闭显示器.exe`：构建产物（依赖 .NET 8 桌面运行时）
- `install.ps1`：构建并创建快捷方式，加 `-Desktop` 同时放到桌面

命令行参数（程序已在运行时，会转交给正在运行的那个实例）：`--off 1,2`、`--on 1`、`--remote`、`--restore`。

需要排查启动耗时：设置环境变量 `MONITOROFF_TRACE=1`，各阶段耗时会写入 `%TEMP%\monitoroff-trace.log`。
